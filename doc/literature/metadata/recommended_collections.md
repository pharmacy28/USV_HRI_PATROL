The RIS already carries tags such as:
`closest_prior_art`, `human_prediction`, `bayesian_search`, `coverage_control`,
`spatial_responsibility`, `maritime_search`, `FULLY_READ`, and `METADATA_VERIFIED`.

Zotero does not reliably reconstruct a custom nested collection tree from ordinary RIS.
The robust workflow is therefore: import all records into one parent collection, then use tags
(or Zotero Saved Searches) to populate child collections.
