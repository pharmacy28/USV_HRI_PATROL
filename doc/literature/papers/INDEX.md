When a PDF is added, classify it before committing:

- USER_AUTHORED
- OPEN_ACCESS_REDISTRIBUTABLE
- PUBLIC_PREPRINT
- PUBLISHER_COPYRIGHTED_OR_UNCLEAR

Only the first three categories may be included in a public repository after
their license or redistribution terms are verified. For the last category,
retain the file outside the repository and index its local filename, DOI,
official URL, and reading status here.
