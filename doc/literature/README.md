# Literature Workspace

This directory is the evidence base for ICRA related-work writing, novelty
checking, bibliography maintenance, and reviewer-response preparation. It is
not a repository of publisher PDFs by default.

## Contents

- **LITERATURE_LEDGER.md** is the core evidence record: verified metadata,
  claim boundaries, relevance, novelty risk, and the next verification step.
- **papers/** contains only PDFs that may lawfully be redistributed and an
  index of both locally retained and local-only papers.
- **related_work_notes/** holds evidence-backed synthesis notes. It must not
  contain unverified Related Work prose.
- **novelty_boundary.md** records what is already covered by prior art and
  the provisional boundary for this paper's contribution.
- The project-root **references.bib** is the canonical BibTeX file. It contains
  the 26-entry user-supplied Zotero export; detailed manuscript use remains
  governed by the ledger's evidence boundaries.

## Reading status

- **FULLY_READ:** primary paper read sufficiently for detailed comparison.
- **FULLY_READ_PRECURSOR:** metadata for a later version is verified and its
  directly preceding conference or technical version was read.
- **PARTIALLY_READ:** primary text read for a limited purpose; the ledger
  identifies that scope.
- **METADATA_VERIFIED:** title, authors, venue, year, and DOI checked, but no
  detailed claim should be made from the record alone.
- **DISCOVERED:** candidate found but not yet metadata checked.

An absent GitHub PDF does not imply that a paper was not read. Publisher PDFs
with unclear redistribution rights remain local-only or in a reference manager;
the index and ledger preserve their metadata, DOI, official URL, and reading
status.
