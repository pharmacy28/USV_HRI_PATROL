# Zotero、PDF 与引用键

1. 用 [USV_HRI_core_literature.ris](USV_HRI_core_literature.ris) 导入原 26 条记录；如果已有集合，先核对 DOI，避免重复导入。
2. 在[当前文献索引](../INDEX.md)定位 PDF。可将对应 PDF 拖入 Zotero 条目，或添加链接附件。跨电脑使用链接附件时需要保留目录/配置 Zotero 基目录。
3. 已有正式引用键见 [references.bib](../../paper/manuscript/references.bib)。如果使用 Better BibTeX，先固定现有键，再配置自动导出；不要无检查地覆盖正式书目。
4. 仓库当前阅读状态属于历史资料，本次只核对 PDF 内容归属和文件完整性。看到 `FULLY_READ` 不表示本轮又完整读了一遍。

本目录实际文件包括 RIS、`doi_list.txt`、`literature_index.csv` 与 `recommended_collections.md`。不再列出原说明中并不存在的 BibTeX 或平台路线图文件。

PDF 的保存与文献权利状态是不同问题；不能因文件存入本仓库就认为它被授予项目的开源许可证。
