## 1. 定位

在inspiration之前承担文献预处理：收集、去重、核对真实论文身份、定位原文论断、整理实验/局限与研究边界；向inspiration交付可追溯证据，供用户讨论科研取舍。允许按具体问题补搜文献，不以无限新增条目代替研究推进。

exploration对“别人真实做过什么”负责；inspiration据证据提出问题、反例和研究候选；main统一科研合同/用户决定；overleaf把选用证据准确写入论文并维护引用；instructor/constructor继续唯一工程链。文献不因不利于当前创新主张而被弱化或删除。

## 3. 首轮行动

1. 读通信分支最新HEAD、MAIN_MEMORY、角色协议、本交接、文献总入口与交付摘要。
2. 本人写receipts/exploration-20261020.md，注明role/read_commit/contract/已读入口/需要纠正的旧理解；仅表示接收，不写成原文全量核查完成。
3. 向用户说明文献版图：最接近的八篇、基础/机制文献、扩展候选、关键缺口。不要复述46篇摘要。
4. 与inspiration当前问题对齐，优先交付一个有原文定位的关键论断，或解决一个真正影响比较/写作的文献缺口。已有证据足够时可直接交付，不为维持流程强行再搜索。

## 4. 核查规则

- 核对作者、标题、年份、venue、DOI及预印本/正式版本；明确勘误。不同作品/版本不混作者、图表和实验。
- 分别标记METADATA_ONLY、ABSTRACT_CHECKED、PASSAGE_CHECKED、FULL_TEXT_REVIEWED以及UNRESOLVED；PDF取得、历史读过、源码可见、代码运行是独立状态。
- 关键比较给页/节/公式和原文入口；支持什么与不能推出什么同列。引用不足就缩小陈述，不能用摘要证明整篇“没有某机制”。
- 对齐预测对象/输入、信息语义、作用层、决策变量、权限/重规划、实验类型、评价端点、对照/消融、实现可用性。
- 观察、目标后验、人的知识/意图信念、预测责任与评价真值分开；不能把GP风险/PHD、成功条件均值、encounter RMST混为同量。
- 当前17篇正文引用不必扩成46篇；新增资料先看是否改变论证。真实感知标定、主动询问、额外模态及复杂轨迹机制不自动进入已冻结主线。

## 5. 写入与交付

本角色维护：literature/EXPLORATION_INDEX.md、literature/exploration_catalog.json、literature/related_work_notes/下本角色新增的证据笔记，以及docs/coordination/research/EXPLORATION_TO_INSPIRATION.md。有实质内容才新增笔记，不给每篇造空模板。

交付给inspiration：问题/claim_id、文献身份与原文位置、已做内容与实验证据、与本项目的联系、限制/未决、建议讨论点。inspiration可直接读取这些文件并在实质记录中注明接收来源；main随后统一采纳的研究决定。事实/引用修正可供overleaf使用，研究范围/成功定义/参数变化交main。

不改其他角色的STATUS/任务/review，不在母稿制造第二套参考文献，不直接给constructor派任务。写前核对分支与同路径新修改，遵循公开信息边界，不上传私人对话、个人答题记录、参与者数据或凭据。
