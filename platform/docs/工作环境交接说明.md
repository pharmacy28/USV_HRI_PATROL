## 6. 合并规则

- 仿真和 ROS 代码放 `platform/`；论文正文放 `paper/`；未验证想法放 `idea/`。
- 不上传 `build/`、`install/`、`log/`、`.TobiiBridge/`、Whisper `.pt` 和 Unity 归档。
- 修改 VRX 上游时同步更新补丁文件并重新构建。
- 当前本地 `config/*.yaml` 和生成 URDF 中仍有 `/home/cyz/vrx_ws` 绝对路径；跨目录复现前需修复路径。
- 在完成路径映射前，不要把 `/home/cyz/vrx_ws` 根仓库直接绑定到 GitHub 后整体 push。

网页端 GPT 或新的 Codex 应先读取本文件，再读取根 `README.md`、`platform/README.md` 和 `idea/` 两份研究文档；实现任务必须返回修改路径、测试命令、测试结果和 Git 提交号。
