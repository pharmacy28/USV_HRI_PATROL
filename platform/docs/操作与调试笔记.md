##推荐：一键启动 VRX 控制系统

cd ~/vrx_ws
./run_vrx.sh

##如果 GUI 太卡，用这个无界面版本：

./run_vrx.sh --headless

##停止全部相关进程：

./run_vrx.sh stop

##如果还有 Gazebo/控制台窗口残留，再执行一次 stop
##现在 stop 会先 TERM 再 KILL，并清理 log/vrx_debug/*.pid 和 /tmp/vrx_voice_ptt_*.json
##stop 也会清理 fleet_state_node 内部使用的 gz topic -e 位姿读取进程

./run_vrx.sh stop

##查看节点和关键 topic：

./run_vrx.sh status

##status 会额外检查重复节点和关键通信边：
##/fleet/manual_target        UI/语音/手柄发出的目标请求
##/fleet/manual_target_state  manual_mux 发布的真实手控目标事实源
##/operator/manual_cmd        手柄控制命令
##/overview/fleet_state       上位机态势图/速度表数据源
##/overview/selected_camera/image_raw  当前 FPV 视频桥接
##/voice/transcript           Whisper 中文识别结果
##/voice/intent               语音命令解析结果
##/mission/request            已校验的“目标艇 -> 8x8棋盘区域”任务请求
##/mission/status             任务接受/拒绝及后续执行状态

##查看系统诊断：

./run_vrx.sh diag

##只启动仿真和控制链，不开控制台：

./run_vrx.sh --no-console

##rqt/rqt_graph 检查通信关系

##常用原则：
##1. 不要只看 UI 高亮。真正控制哪艘船以 /fleet/manual_target_state 为准。
##2. 态势图编号以 /overview/fleet_state 里的 name/source 为准，source 应该是 gz_named_pose。

##4. 语音识别必须看到 /voice/transcript 有中文文本；只有 /voice/whisper_status 在线不算完成。

##/joy -> /eightbitdo_pad -> /operator/manual_cmd -> /manual_mux -> /wamv_XX/thrusters/*/thrust
##/joy -> /whisper_bridge_node -> /voice/transcript -> /voice_command_node -> /voice/intent
##/voice/intent -> /mission_gateway_node -> /mission/request + /mission/status
##/voice_command_node -> /fleet/manual_target -> /manual_mux -> /fleet/manual_target_state
##/overview_fleet_state -> /overview/fleet_state -> /operator_console_node
##/overview_selected_camera_relay -> /overview/selected_camera/status -> /operator_console_node

##正常时：

##语音识别

##当前 ASR 使用本机 ~/miniconda3/envs/voice 中的 Whisper，不调用云端转写。
##Windows 虚拟麦克风由独立脚本 src/voicebridge/windows_audio_udp_sender.py 持续发送：
##VRXA v1，16kHz，单声道，PCM16LE，默认 UDP 15556；眼动继续使用 UDP 15555。
##它不依赖 Unity；Unity 只负责原有眼动发送。
##Windows 先列输入设备，再用设备编号或名称的一部分启动：

python src/voicebridge/windows_audio_udp_sender.py --list-devices
python src/voicebridge/windows_audio_udp_sender.py --target-host LINUX_IP --device "虚拟麦克风名称"

./run_vrx.sh --voice --voice-backend udp --voice-udp-source-ip WINDOWS_IP

##若暂时不接手柄，必须同时加 --no-joy --no-pad --voice-open-mic。

##推荐先列出输入设备：

./run_vrx.sh voice-devices

##用 PulseAudio/PipeWire 源启动。索尼 XM5 一般要连接到 HFP/HSP 输入模式，source 名通常类似：
##bluez_input.XX_XX_XX_XX_XX_XX.0
##如果只看到 alsa_input.pci-...analog-stereo，说明当前用的是电脑模拟/板载麦克风，不一定是耳机麦克风。

./run_vrx.sh --voice --voice-backend pulse --voice-device SOURCE_NAME

##按住 A 说话，松开 A 后才会转写；按 B 取消当前识别结果。
##A 键释放带 0.2s 去抖，避免蓝牙/驱动瞬时抖动导致录音自己提前停止。
##可调参数：
##--voice-ptt-release-debounce 0.2
##--voice-no-speech-threshold 0.8
##--voice-threshold 0.02

##要确认真的识别成功，看：

ros2 topic echo /voice/whisper_status
ros2 topic echo /voice/transcript
ros2 topic echo /voice/intent

##当前支持的语音意图示例：
##选择目标：选择一号船 / 切换四号船 / WAMV十号
##切换界面：切换FPV / 切换全局态势 / 打开网格
##棋盘目标：WAMV二号到E5 / 十号船去A1
##语音不发布连续推进/转向命令，/operator/manual_cmd 仍由手柄独占。
##棋盘目标经 /mission_gateway_node 校验后发布 /mission/request；不会切换 /fleet/manual_target。
##后续路径规划器订阅 /mission/request，在指定大区域内选择自由空间目标点，再发布 /mission/plan。

##如果 UI 显示“未识别到有效语音”，说明流程走完了，但 Whisper 没听到可识别语音。
##此时优先换正确麦克风源，或者降低环境噪声/调整系统输入音量。




##注意力热力图

##眼动桥接由你手动启动，不放进 ./run_vrx.sh
##operator_console 会直接订阅 /tobii/gaze，并在右侧“注意力热力图”面板内部生成热力图
##注意：只启动 gaze_lsl_bridge.py 只能说明 UDP -> LSL 通了
##注意力热力图需要 gaze_receiver.py 继续把 LSL 转成 ROS /tobii/gaze
##所以正常运行 VRX 时仍然是：

cd ~/vrx_ws
./run_vrx.sh

##另开终端 1：Windows Unity UDP -> Linux LSL

cd ~/vrx_ws
source .TobiiBridge/bin/activate
python src/eyetrackerbridge/gaze_lsl_bridge.py

##另开终端 2：LSL -> ROS /tobii/gaze

cd ~/vrx_ws
source /opt/ros/humble/setup.bash
source install/setup.bash
source .TobiiBridge/bin/activate
python src/eyetrackerbridge/gaze_receiver.py --reconnect --publish-invalid

##不要加 --no-ros，否则不会发布 /tobii/gaze，控制台热力图会一直 WAITING

##检查眼动 topic：

ros2 topic list | grep tobii
ros2 topic info /tobii/gaze -v
ros2 topic echo /tobii/gaze --once

##正常应该看到 /tobii/gaze 的 Publisher count: 1
##如果 Publisher count: 0，说明 gaze_receiver.py 没有运行或没有成功初始化 ROS

##热力图面板状态含义：

WAITING /tobii/gaze        ##没收到眼动 topic
NO VALID GAZE total=N      ##收到了，但 valid 全是 false
xx.xHz gaze=(x,y)          ##正常显示热力图
