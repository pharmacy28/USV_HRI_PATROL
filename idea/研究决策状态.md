# 研究决策状态

本文件是人类/ChatGPT 研究讨论与 Codex 实现之间的持久通信台账。它记录当前科研决策的权威状态，并优先于 `idea/` 中较早文档的历史性或候选性表述。

## 状态契约

本台账只使用三种科学状态：

- `CONFIRMED`：已经明确确认的研究范围、约束、当前架构或待检验假设；可以作为实现要求，但“待检验假设”不等于已经得到实验支持。
- `CANDIDATE`：仍需比较、论证或验证的实现/研究选项，不是冻结要求。
- `OPEN`：尚未解决的问题；必须保留为开放状态，直到有明确依据和决策。

> Only decisions explicitly marked CONFIRMED may be treated as fixed research requirements. CANDIDATE items are implementation/research options. OPEN items must not be silently decided by Codex.

## CONFIRMED

### Research scope

- 搜索地图来自前期 UAV 侦察得到的已知粗粒度二维海上障碍栅格。
- 恰好存在一个目标。
- 目标静止。
- 目标位置未知，且位于可搜索自由空间中。
- 障碍格栅的目标概率为零。
- 在所有可搜索自由格栅上维护归一化贝叶斯信念：

  `b_i^t = P(X = x_i | Z_{1:t})`

  `sum_i b_i^t = 1`

### Human input and belief

除非显式引入一个可辩护的概率化人类观测模型，否则人类输入不得直接修改目标后验信念。语音、眼动、手柄、选定目标点和预测目标点本身都不是目标存在观测。

### Core planning architecture — current architecture

当前确认的闭环架构为：

```text
Bayesian belief
→ belief-aware clustering
→ human-constrained re-clustering
→ A* path generation
→ path-dependent USV–center assignment
→ execution
→ sensing
→ Bayesian posterior update
→ event-driven replanning
```

### Fixed-center semantics

- 聚类中心表示搜索目标点。
- 人工指定或预测的目的地可以作为固定中心。
- 所有非障碍、可搜索自由格栅都重新参与聚类。
- 固定中心保持不动。
- 只更新自主中心。
- 不得只变换旧的自主簇。
- 不得手工删除所谓残余搜索区域。

### Human collaboration

可用交互模态可以包括眼动、语音和手柄。人类输入可以：

- 选择一艘 USV；
- 指定一个点；
- 指定一个区域；
- 指定一个方向；
- 直接控制运动。

显式命令的 USV–目的地配对在命令有效期间锁定，并从自主重分配中排除。

### Human destination prediction — concept

对于一艘人控 USV，架构可以估计未来位置：

`\hat p_h(t+H)`

该概念关注人工干预的未来空间后果，而不是把预测位置当作目标存在证据。

### Core research hypothesis — hypothesis to test

> Predicting the future spatial consequence of human intervention and fixing that predicted destination during belief-driven re-clustering allows the remaining autonomous USV fleet to proactively redistribute search responsibility.

这是已确认需要检验的核心假设，但**尚未被证明为真，也不是实验结论**。

### Assignment architecture

对每一个有资格参与自主分配的 USV–中心配对，先规划避障路径：

`\mathcal P_{rj} = A*(p_r,c_j;M)`

分配代价必须依赖已规划路径，而不能只使用原始欧氏中心距离。锁定的人工配对必须在自主分配前排除。确认的依赖顺序是：

```text
belief-aware clustering
→ centers
→ pairwise obstacle-aware A* paths for eligible pairs
→ path-dependent assignment cost
→ Hungarian/equivalent optimal assignment
```

### Historical-document conflict protection

较早的研究框架可能描述了等价于以下内容的顺序：

```text
clustering → Hungarian → A*
```

当前确认的架构要求：

```text
clustering
→ pairwise obstacle-aware A* paths
→ path-dependent assignment cost
→ Hungarian/equivalent optimal assignment
```

原因是分配代价依赖已规划路径。不得把历史顺序静默传播到实现或论文正文中。

## CANDIDATE

### Prediction algorithm

Random Forest 当前只是一种候选预测器，不是已确认方法，也不能仅因使用它而主张科研贡献。

### Event-trigger candidate set

潜在的事件驱动重规划触发条件包括：

- USV 到达；
- 人工目的地改变；
- 预测目的地变化超过一个有依据的阈值；
- 受控 USV 改变；
- USV–目的地命令改变或取消；
- 分配失效；
- 可选的最大重规划间隔。

精确的触发公式仍为 `OPEN`。

### Assignment cost

初始简单候选包括：

`J_{rj} = L(\mathcal P_{rj})`

或者估计航行时间。最终选择仍为 `OPEN`，不能把路径长度当作已经冻结的唯一代价。
